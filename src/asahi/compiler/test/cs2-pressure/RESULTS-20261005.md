All crashes hit the same NIR divergence stage assertion before allocation.
Neither set emitted any spill compilation. `AGX_MESA_DEBUG=spill` was not
initialized on the separate Apple9 path, so the requested forced-spill results
must not be counted as forced-spill coverage. No expected-failure classification
was configured. The skip is `opphi.vartype_longvec`. Assertions and NIR validation
were enabled in all GPU runs. Fix both setup defects before repeating CTS.

frame-IADD cases and 59 rewrite cases. Word indices include 0, 1, 63, 64, 95,
96, 127, 128, 255, 256, 405, 416; alias and neighbor guards, retained reads,
changed seeds and multigroup cases pass. No-gap cases retain a full WAIT and

at device creation because the hook intercepted an internal fragment shader;
the runner now scopes the hook after device creation. The compiler and SPIR-V
were unchanged. See the high-registers branch FRAME-PROBE.md for full provenance.
